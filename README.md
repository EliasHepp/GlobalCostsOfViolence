# Global-Costs-of-Violence

This repository contains the codebook, datasets and scripts reproducing the central prevalence and cost data used in the book Worse than War: The Global Costs of
Violence by Anke Hoeffler and James D. Fearon.

## Codebook

The codebook describes all dataset variables, lists data sources and explains data manipulation steps. In addition, it provides a brief overview over the cost estimation methods applied.

## Scripts and Datasets

The script *rep_prev_cost* generates the datasets *vsl_cost_cntr.csv* and *prevalence_cntr_averages.csv* from the source data.
The script *rep_gdp_cf* generates the datasets *gdp_cntr_totloss.csv* and *gdp_cntryr_cfloss.csv*.

A detailed overview of the datasets is given in the codebook.
